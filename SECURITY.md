# Security

Please report security problems privately, through GitHub's
[private vulnerability reporting](https://github.com/JR91387/wagtail-kanban-content-calendar/security/advisories/new),
not in a public issue. You'll get a reply as soon as possible, and a fix will be released before the problem is
made public.

Supported: the latest release.

Problems in Wagtail itself go to the Wagtail team: see https://docs.wagtail.org/en/stable/contributing/security.html
